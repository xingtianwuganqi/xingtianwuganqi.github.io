关于我 | About Me

阅读时长: 4 分钟

一名普通的程序员，一个仍在探索技术、产品与人生的独立开发者。

你好，欢迎来到我的博客。

我是一名有着多年开发经验的程序员，主要从事 iOS 客户端开发，熟悉 Swift、Objective-C、SwiftUI 和 UIKit，也在不断探索 Go、Python、Android 以及 AI Agent 等技术。

这里记录我的技术学习、独立开发经历，以及关于工作、生活和个人成长的思考。

💻 关于技术

我的技术生涯主要围绕移动端开发展开。

这些年，我参与过运动分析、智能硬件、视频处理等不同类型的项目，接触过蓝牙通信、实时数据处理、音视频开发、应用架构设计、性能优化以及 App Store 上架等技术领域。

随着经验积累，我逐渐意识到，程序员不能只关注如何实现功能，更应该理解功能背后的业务需求、系统设计和产品价值。

除了 iOS，我也在使用 Go 进行后端开发，使用 Python 探索 AI Agent，希望逐渐具备从客户端、服务端到 AI 应用的完整开发能力。

目前，我主要关注这些方向：

  • iOS 开发：Swift、SwiftUI、UIKit、Swift Concurrency
  • 后端开发：Go、Gin、MySQL、Redis、Docker
  • AI 应用：Python、LLM、AI Agent、工具调用与任务规划
  • 跨平台探索：Android、Jetpack Compose

技术永远学不完。我更希望围绕实际问题持续积累，而不是追逐每一个新框架。

🚀 关于独立开发

工作之外，我一直在尝试开发属于自己的产品。

其中，对我意义特别的一款 App 叫 「真命天喵」。

它是一款宠物领养与送养应用，希望让需要新家的猫猫狗狗，被真正愿意照顾它们的人看见。送养者可以发布宠物的照片、介绍和所在位置，领养者则可以浏览信息、寻找附近的宠物，并联系送养者进一步沟通。

这个项目源于我与猫咪相处的经历。大约在 2021 年，我把最初的想法做成了 iOS App，后来又陆续尝试 Android 和小程序。一路走来，除了开发和上架，还要处理信息真实性、防骗提醒、用户隐私等问题。

它没有带来可观的收入，但我仍然愿意维护它。因为对我而言，每一条真实的领养信息背后，都可能是一只等待新家的小生命。

除此之外，我还开发过：

  • VeloPure：面向骑行爱好者的运动记录应用。
  • MotionText：探索文字动画与视频生成的创作工具。
  • Text Wall：提供文字壁纸制作与图片拼接功能的应用。

这些尝试让我明白：把产品开发出来，与做出真正被需要的产品，是两种不同的能力。 我开始更认真地思考用户需求、产品定位、推广渠道和长期运营。

🤖 关于 AI 与未来

AI 的快速发展，让我重新思考程序员未来的价值。

相比只把 AI 当作写代码的工具，我更想理解它如何完成复杂任务。因此，我开始从零构建自己的 Coding Agent，学习工具调用、任务规划、状态管理、上下文压缩和结果验证。

这个过程并不轻松，一个 Bug 可能要排查很久。但我相信，真正有价值的学习，不只是知道某项技术是什么，而是能够亲手把它实现出来。

🌱 关于成长

这些年，我经历过项目失败、产品无人问津，也经历过职业上的不确定性。

随着年龄增长，我越来越清楚地认识到：不能把全部希望寄托在某一门技术或一份工作上。技术能力是基础，产品思维、持续学习和创造独立收入来源的能力，同样重要。

我希望未来能成为一名真正具备产品能力的独立开发者，拥有更多选择工作和生活方式的自由。现在距离这个目标还有很长的路，但我愿意继续走下去。

📝 关于这个博客

这里不会只有技术教程，我会持续分享：

  • 技术学习：iOS、Swift、Go、Python、AI Agent
  • 独立开发：产品设计、开发实践、上架运营与复盘
  • 职业成长：技术转型、职业选择与个人思考
  • 生活记录：读书、投资、生活感悟与自我成长

我不是什么技术大神，也没有特别成功的创业经历。

只是一个普通程序员，希望通过持续学习、实践和记录，让自己一点点变得更好。

写代码是我的工作，创造产品是我的追求，持续成长是我希望坚持一生的事情。

感谢你的阅读。
